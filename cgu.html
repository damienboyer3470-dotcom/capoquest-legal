2. Objet du service

CapoQuest propose des questionnaires à choix multiples (QCM) pour aider à préparer le concours de Caporal de sapeur-pompier professionnel : révision par thèmes, suivi de progression, succès, classements entre amis, et, avec l'abonnement Premium, des fonctions supplémentaires (voir les conditions de vente).

4. Fonctionnement : vies, chrono, validation

  • Les comptes gratuits disposent d'un nombre limité de vies : une mauvaise réponse, ou un temps écoulé, en fait perdre une. Elles se rechargent selon les règles affichées dans l'application. L'abonnement Premium donne des vies illimitées.
  • Chaque question est chronométrée (20 secondes) dans les QCM pour les comptes gratuits, et dans les examens blancs pour tous. Les comptes Premium n'ont pas de limite de temps sur les QCM classiques.
  • Un QCM est validé à partir de 80 % de bonnes réponses (par exemple 16 sur 20).
  • Les règles, quotas et fonctionnalités peuvent évoluer pour améliorer le service.
